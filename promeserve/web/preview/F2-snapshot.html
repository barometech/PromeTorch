Q4_K блок-структура

Q4_K — это блочная квантизация: 256 значений упакованы в 144 байта (~4.5 bpw). Структура одного super-block:

ПолеРазмерНазначение
dfp16 (2 B)главный масштаб
dminfp16 (2 B)минимум
scales[12]96 bits6 sub-block scales × 6 bits + 6 mins × 6 bits
qs[128]1024 bits256 квантованных 4-bit значений

Для NMC4 ключевая инструкция — векторная распаковка nibble:

c 
// Q4_K dequant — vfpu intrinsics dlot4-style
static inline void dequant_q4k_block(
    const block_q4_K* __restrict__ b,
    float* __restrict__ out)
{
    const float d    = ggml_fp16_to_fp32(b->d);
    const float dmin = ggml_fp16_to_fp32(b->dmin);
    for (int j = 0; j < QK_K/32; ++j) {
        uint8_t sc, m;
        get_scale_min_k4(j, b->scales, &sc, &m);
        const float scale = d   * sc;
        const float bias  = dmin * m;
        // ... unpack 32 nibbles
    }
}
