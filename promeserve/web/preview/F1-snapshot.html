Объясни как работает Q4_K квантизация в GGUF и почему она работает быстрее на Эльбрусе E8C2.

Ассистент

Q4_K квантизация в GGUF

В формате Q4_K каждый супер-блок содержит 256 весов и хранится как:

  • d (fp16) — общий масштаб супер-блока
  • dmin (fp16) — общий минимум
  • scales[12] — 6-битные scale/min на каждый из 8 sub-блоков по 32 веса
  • qs[128] — 4-битные нибблы значений (256 × 4 bit = 128 байт)

Формула декода: w[i] = d * scale[sub] * q[i] + dmin * min[sub].

Почему быстро на Эльбрусе

  1. FMA в SIMD: одна операция fma_pack4 делает 4 умножения с накоплением — идеально подходит для деквант+dot.
  2. NUMA-aware sharding: 4 NUMA-домена × 8 ядер = 32 потока, веса дробятся по строкам матрицы.
  3. 2.5 GB/pass вместо 5.9 GB у FP16 → bandwidth-bound decode упирается в кэш L2/L3.
c 
// Dequant one Q4_K super-block on Elbrus E2K
void dequant_q4k_block(const block_q4_K* b, float* out) {
    const float d = GGML_FP16_TO_FP32(b->d);
    const float dmin = GGML_FP16_TO_FP32(b->dmin);
    for (int j = 0; j < 8; ++j) {
        uint8_t sc, m;
        get_scale_min_k4(j, b->scales, &sc, &m);
        const float d_sub = d * sc;
        const float m_sub = dmin * m;
        for (int k = 0; k < 32; ++k) {
            const uint8_t q = b->qs[j*16 + (k >> 1)];
            const int nib = (k & 1) ? (q >> 4) : (q & 0x0F);
            out[j*32 + k] = d_sub * nib - m_sub;
        }
    }
}

А почему Q6_K работает заметно медленнее, ведь там тоже супер-блок 256 элементов?

Ассистент

Q6_K vs Q4_K — разница в пропускной

  • Q6_K = 6 bit / weight → 210 B / block (vs 144 у Q4_K)
  • Distill для decode: 3.4 GB/pass на 4B параметрах vs 2.5 GB у Q4_K — ×1.36
  • Unpack 6-битных значений сложнее: нибл + 2 бита из qh. Shift-формулы: ql shift = 4*((i//64)%2), qh shift = 2*((i//32)%4).

На Эльбрусе мы реально измерили 2840 rows/sec на Q6_K K=2560 (16 ядер). См. nm_quad_qwen/nmc_q6k_gemv_orig.c.

На Qwen3-4B Q4_K_M смешивает Q4_K и Q6_K: attn_v и ffn_down ≈каждый 3-й слой — Q6_K, остальные — Q4_K. Dispatch только через ttype, hardcode даёт NaN с layer 4.
