Источник: 2 share-диалога DeepSeek (5 проблем эксплуатации) + 5 Opus
implementation-планов (`2026-06-03_*.md`). HEAD = 59822c7.

DeepSeek дал верное **направление**, но видел только README снаружи и
галлюцинировал детали. Ниже — что реально делать, отсортировано по
value/risk/effort. Hot path (qwen3-4b TP-4 = 10.9 tok/s) НЕ трогаем.

## Что DeepSeek наврал (НЕ копировать)

| Ошибка DeepSeek | Реальность |
|-----------------|------------|
| "в репозитории нет CI/CD" | 5 workflows: ci/build/elbrus-sim/wheels/release.yml |
| `-march=thomas` для NM Card | NM Quad = DSP с отдельным SDK, не gcc-таргет |
| `-mtune=elbrus-8c` хардкод | это убитый баг T2 (detect_e2k_march) |
| `crossbuild-essential-e2k` пакет | не существует; компилятор = МЦСТ lcc |
| `add_library(core SHARED src/*.cpp)` | ядро = 7 .cpp, torch/ = 127 header-only |
| gcc для Эльбруса | lcc/l++, НЕ gcc |
| CPM.cmake авто-качает eigen | eigen не используем, на e2k нет интернета |
| `FROM scratch` Docker | нужны libc/libstdc++/libeml; e2k = Alt/Astra не debian |
| Docusaurus | overkill для solo-репо, MkDocs проще |

## Приоритизированный план

### P0 — мелкие фиксы корректности (нулевой риск, делаем сразу)

1. **Version single-source** — 3 рассинхрона: pyproject `0.1.0a1` /
   CMakeLists `0.1.0` / `python/csrc/init.cpp` `0.2.0`. Свести к одному.
2. **CI `|| true` removal** — `ci.yml:50` continue-on-error, `build.yml:35-47`
   `|| true` на ctest/c10_tests/aten_tests. Зелёный badge врёт.
3. **gen_stats.py + STATS.md** — single source для чисел (backward=121,
   CUDA=149, optimizers=16, tests=907). CI-гейт `git diff --exit-code`.

### P1 — CI/CD честность (низкий риск, облако)

4. **promeserve pytest job** в CI (сейчас только вручную)
5. **wheels.yml**: убрать cp39 (EOL), добавить arm64 если возможно
6. **examples** → отдельный advisory-job (не валит основной badge, но виден)

### P2 — универсальный сборщик (низкий риск, аддитивно)

7. **CMakePresets.json** + переиспользовать 7 существующих toolchain-файлов.
   BLAS остаётся runtime auto-detect. build-elbrus.sh НЕ растворять
   (рантайм-детект железа невыразим в статичном preset) — заменить только
   финальный configure на `cmake --preset`. x86/baikal → тонкие обёртки.
   ⚠ Полная верификация требует прогона на ELBRUS_HOST/e16c (TP-4 = 10.9 tok/s).

### P3 — артефакты «скачал-запустил» (средний)

8. **PromeServe release asset** — install-rules в promeserve/CMakeLists +
   release job (бинарь + web/ + README). Самый ценный «скачал-запустил».
9. **Trusted Publisher** на pypi.org — ручная регистрация (документировать).
10. Опционально 1 tar.gz под Эльбрус v5 (8C2) — build-on-target уже решает.

### P4 — модульность (низкий риск, аддитивно)

11. **prometorch_core / prometorch_backends** INTERFACE-агрегаты (1 имя вместо 8)
12. **docs/ARCHITECTURE.md** — логические слои поверх существующих таргетов
13. Чистка корня: 30+ .bat, 60+ vit_*.log, orphan test_*.py → archive/gitignore
   (полный DeepSeek рефактор core/apps/deploy = 1-2 недели, НЕ оправдан)

### P5 — docs consolidation (средний)

14. **MkDocs Material** + GH Pages (`docs.yml`). User-facing only.
    CLAUDE.md/JOURNAL/audit/research/strategy — НЕ публикуются (internal).
15. **README split** ≤250 строк (сейчас 1422), остальное в сайт.
16. **CLAUDE.md Phase-table** апдейт (cuDNN/FlashAttention/Conv3d/CTCLoss
    помечены BROKEN — реально работают с апреля).
17. TECHNICAL_SPECIFICATION.md → archive.
