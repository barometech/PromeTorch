# Внешние справочные материалы

Официальная документация МЦСТ (Эльбрус) и НТЦ «Модуль» (NeuroMatrix) —
**проприетарная** и не является результатом проекта PromeTorch. Раньше эти PDF
лежали прямо в репозитории (`docs/elbrus/`, `docs/nmquad/`, `docs/elbrus_isa/`,
~31 МБ), но распространять их под лицензией PromeTorch мы не вправе без
письменного разрешения правообладателя (аудит 2026-07-24, P1-1). Поэтому здесь
— только ссылки на первоисточники.

## Эльбрус / E2K (МЦСТ)

- Официальный сайт МЦСТ: http://www.mcst.ru
- Портал разработчика Эльбрус (руководства по программированию, LCC,
  оптимизации, ISA): http://www.mcst.ru/programmirovanie
- Форум/поддержка разработчиков: http://mcst.ru/support
- Документация LCC (компилятор): поставляется в составе SDK Эльбрус.

Ранее вендоренные файлы (получать у МЦСТ по запросу):
`elbrus_prog_guide_v1.x`, `elbrus_porting_guide`, `book_elbrus`,
`lcc_auto_parallelization`, `eml_acceleration_paper`,
`elbrus_binary_translation`, `qemu_e2k_user_manual` и др.

## NeuroMatrix / NM Card / NM Quad (НТЦ «Модуль»)

- Официальный сайт НТЦ «Модуль»: http://www.module.ru
- Документация по процессорам серии NM (NM6408 / K1879ВМ8Я): получать у
  НТЦ «Модуль» по запросу / в составе SDK.

Ранее вендоренные файлы (получать у НТЦ «Модуль»):
`CONVENTN.pdf`, `nm6408_processor_errors.pdf`, `K1879vm8_re.pdf`.
