## Топ-10 самых критичных находок (требуют immediate action)

1. **Engine race condition** (`error_handling #6`) — singleton мутирует
   `Node::dependency_count_`, `visited_`, `accumulated_grad_` без mutex.
   Параллельные `loss.backward()` дают **silent incorrect gradients**.
   Симптомов нет — самый опасный bug в коде.

2. **PromeServe path traversal + RCE chain** (`security #1+#9+#17`) —
   `sandbox_path()` ловит только литералы `..`, не нормализует
   backslash/symlink/realpath. Через `write_file` злоумышленник может
   подменить `~/.promeserve/mcp.json` → MCP spawn'ит arbitrary command
   после restart. HTTP listener bind на `INADDR_ANY` без auth/TLS →
   **LAN-доступный RCE**.

3. **`PT_ASSERT → assert()` отключается с `-DNDEBUG`** (`error_handling #11`).
   ВСЕ runtime invariants под `PT_ASSERT` исчезают в Release builds.
   Тихие dead checks — массивно.

4. **README false claims** (`docs_vs_code`) —
   * FlashAttention заявлен "отключён", реально подключён через `scaled_dot_product_attention`
   * `create_graph` заявлен "не работает", реально работает
   * FP16/BF16 dispatch заявлен, **0 callsites** в aten/
   * NMCard MNIST 93.64% повторяется, в BENCH_NMCARD.md написано 88.94%

5. **CI скрывает падения за `|| true` / `continue-on-error`** (`build_ci #2`) —
   зелёные бэйджи ничего не гарантируют. Тесты могут все падать, badge
   green.

6. **PromeServe 6354 LoC, 0 tests** (`test_gaps`) — весь HTTP/MCP/tool_call/
   model_loader без CI. **Закрываем в этом коммите** — добавляем
   `tests/promeserve/`.

7. **GGUF loader unbounded counts** (`error_handling`) — `tensor_count`,
   `metadata_kv_count`, `n_dims`, ARRAY `count` без upper bound. Одиночный
   malformed файл = OOM. Surface для DoS пользователей загружающих веса
   с HF mirror.

8. **NM Quad 3 tok/s физически недостижим** (`nmcard_nmquad`) — bandwidth
   ceiling = 1.25 tok/s. Цель из MEMORY.md недостижима на этом железе.
   Кумулятив всех optimization paths = projection ~0.5 tok/s. Нужны
   Q3 (lossy) / batch>1 / другое железо для 3 tok/s.

9. **Python API coverage реально 25-30%, не 35-45%** (`python_api`).
   `nn.MultiheadAttention`, `nn.RMSNorm`, `Dataset` base — отсутствуют.
   `amp.autocast/GradScaler`, `jit.compile`, `compile()` — silent
   no-op stubs (loss возвращается unchanged без warning).

10. **115 orphan C++/CUDA файлов** (`dead_code`) — 0 references в коде +
    CMake, ~677 KB / 18 831 LoC. Топ-кандидаты на DELETE:
    `promeserve/model_loader.h` (заменён), `torch/compile/promepile_inference.h`
    (никем не используется), 8 root-level scratch test'ов.

| NgramDraft hash-map | `speculative_draft.h:63-97` | +3-5% | Low |

52 ms theoretical, текущие 92 ms = 57% utilization. 30 tok/s = 33 ms/token
достижим **только при FP16 KV + closing attention parallelism gap**.
