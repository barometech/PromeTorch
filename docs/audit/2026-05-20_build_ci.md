**Дата:** 2026-05-20
**Скоуп:** root `CMakeLists.txt`, sub-`CMakeLists.txt` (examples/, tools/, benchmarks/, promeserve/), toolchain-файлы (`cmake/toolchains/`), `pyproject.toml`, `setup.py`, `.github/workflows/*.yml`, скрипты `scripts/build-*.sh`, `Dockerfile*`.

## Сводка (короткая)

Корневой `CMakeLists.txt` — 1654 строки, **35+ опций / find_package блоков**, монолитен. Хорошие практики: cuDNN/EML/NUMA `find_package`/`find_path` с graceful fallback, генератор-expression `$<$<COMPILE_LANGUAGE:CXX>:...>` для MSVC vs nvcc разделения, поддержка 6 toolchain'ов (e2k, baikal-m/s, alt, astra, redos) + ROCm/MPS — это **сильная** часть.

**Главные риски:**
1. CI **continue-on-error** на ВСЕХ тестах + `\|\| true` в build.yml — зелёный badge ничего не гарантирует (LOW visibility on regressions).
2. **FlashAttention.cu всегда компилируется** даже с `BROKEN` статусом — 30+ секунд waste в каждом CUDA-билде + потенциал dead-symbol export.
3. **License headers отсутствуют** во ВСЕХ исходниках — для Apache 2.0 это формальное нарушение Section 4.b ("...attribution notices...") хотя LICENSE-файл есть.
4. **pyproject vs CMake versions inconsistent** (3.18 vs 3.20 vs 3.21 для ROCm).
5. **Dead test files** в `tests/io/` — 8 файлов никогда не строятся.
6. **`setup.py` hardcoded MSVS2019 path** — пользователь без BuildTools уходит в silent Python-fallback.

**Опции:** все 14 declared options используются, кроме `PT_USE_AVX` (без 2) — semi-dead. `PT_USE_LINQ`, `PT_USE_NMQUAD`, `PT_USE_MPS`, `PT_USE_NMCARD`, `PT_USE_CUDNN`, `PT_USE_EML_BLAS`, `PT_USE_TUDA`, `PT_USE_ROCM`, `PT_USE_CUDA`, `PT_USE_MIOPEN`, `PT_USE_SYSTEM_BLAS`, `PT_USE_NUMA`, `PT_HAVE_NUMA_H`, `PT_DEBUG_HTTP`, `PT_BUILD_PYTHON`, `PT_BUILD_VALIDATE`, `PT_BUILD_GENERATED_TESTS`, `PT_BUILD_DEEPSPEED_TESTS` — все живые с `#ifdef`-callsites.

**Cross-compile:** `CMAKE_SYSTEM_PROCESSOR` checks везде валидны (regex `e2k|elbrus`, `aarch64|arm64|ARM64`, `x86_64|AMD64|x86`). Toolchain-файлы установлены, но `_E2K_MARCH` default `elbrus-v4` грубоват для E16C (см. #23).

**Hardcoded paths:** все обёрнуты в `HINTS` (CMake) или `command -v` fallback (shell). Только `setup.py` (#5) и Docker images (#18) — pinned tag без digest.

**Generated files:** `gguf_arch_dispatch.gen.h` / `parser.gen.cc` не найдены (не существуют), но `CMakeLists.txt:451-463` создаёт stub'ы в source tree — анти-pattern (#24).
