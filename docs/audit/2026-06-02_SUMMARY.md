## Топ-15 проблем (требуют immediate action)

### 🔴 CRITICAL (5)

1. **Q3_K dequant сломан 4 баггами** (`gguf_dequant.h:476-525`, audit #15)
   - `is_type_supported(Q3_K)=true` → DeepSeek/Mistral-Large модели дают **silently garbage**
   - Был в 20.05 audit, **НЕ исправлен**. Известный bug, скрыт `stub TBD` comment

2. **TP KV-cache OOB write** (`gguf_model.h:5942-5946`, audit #14)
   - `forward_decode_cpu_tp` пишет без `past_len < kv_max_seq` check
   - Heap corruption на long-context. Non-TP path такую проверку имеет — TP пропустил

3. **CMake intrinsic auto-detect — dead code** (audit #12 R16)
   - Мой commit `45f9acf` добавил `PT_HAVE_*` defines, но `q8_soa_repack.h:44-53`
     до сих пор guard'ит через `__iset__ >= 5`. Defines читает только сам себя.
   - **Любое сегодняшнее claim о CMake auto-detect — false.**

4. **Engine race condition** (audit #18 #A)
   - `Node::mutex_` объявлен (engine.h:239), но engine его НИКОГДА не лочит
   - Параллельные `loss.backward()` → silent wrong gradients

5. **PromeServe RCE chain** (audit #18 #B)
   - path traversal в `sandbox_path()` + bind на `INADDR_ANY` + no auth
   - Один POST → запись `~/.promeserve/mcp.json` → MCP spawn arbitrary command

### 🟠 HIGH (5)

6. **OpenBLAS `extern "C" cblas_sgemm(int, ...)` конфликтует** с `/usr/include/cblas.h`
   (audit #12 R17). На E16C build падает на redeclaration error.

7. **GGUF unbounded counts** — `count=UINT64_MAX` → OOM (audit #14 #21, #18 #D)
   - Reserve есть, но цикл по полному count.

8. **NUMA tile globals race** в `hot_loops.cpp:115-127`, `201-210` (audit #14)
   - `g_B_cache[node]`, `g_numa_tiles[i]` без mutex
   - Concurrent sgemm() → corruption. Relevant для PIR Local SGD

9. **Frontend XSS через DOMPurify не вызывается** в marked() (audit #20)
   - `marked(text)` без `DOMPurify.sanitize` → потенциальный XSS через assistant output

10. **4 env vars решают корректность LLM output** (audit #19)
    - `PT_PER_BLOCK_SCALE`, `PT_LM_HEAD_FP`, `PT_NO_FFN_SOA`, `PT_SYSTEM_PROMPT`
    - Если юзер не знает — модель даёт калич. Должны быть в CLI/config
