# Аудит test gaps PromeTorch — 2026-05-20

Методика: подсчёт LoC production-кода (`*.h/*.cpp/*.cu`) против существующих тестовых
файлов (`test/cpp/*.cpp`, `tests/*.cpp`, `tests/io/*.cpp`, `python/tests/*.py`).
Test «касание» = grep по имени класса / namespace / заголовка в test файлах.

Severity scale:
- **CRITICAL** — public API/inference path с 0 callsites в test/, риск silent regression
- **HIGH** — есть compile-time test, но 0 functional coverage; либо bit-exact required, но не проверяется
- **MED** — есть частичные тесты, но крупные подсистемы вне покрытия
- **LOW** — small surface или dead code
