# PromeTorch — Обновы на 10 день лета! ☀️

Большой апдейт: быстрее, безопаснее, и наконец-то **собирается у всех**.

## 🚀 Производительность и квантизация

- **pre-SINQ GGUF (Huawei, Apache-2.0)** — теперь PromeTorch грузит
  Sinkhorn-квантизованные модели Huawei как drop-in, без единой строки
  изменений. На Эльбрусе 8C2: **11.5 tok/s** (быстрее обычного baseline 10.6!).
- **Q5_K в Tensor-Parallel** — добавили K-slice для Q5_K. Любой Q4_K_S /
  Q5_K GGUF в TP-режиме больше не падает в медленный fallback (было 8.1 →
  стало 11.5 tok/s на той же модели).
- **Q3_K dequant переписан bit-exact** по GGML — раньше выдавал «мусор»
  молча на Q3_K-моделях (DeepSeek/Mistral), теперь корректно.

## 🔒 Безопасность

- **PromeServe** (LLM-сервер) теперь слушает **127.0.0.1 по умолчанию**, не
  весь мир. Наружу — только осознанно через `PROMESERVE_HOST=0.0.0.0`.
- **Sandbox файловых инструментов** усилен (`weakly_canonical` + проверка
  корня) — закрыт path-traversal/symlink-escape.
- **GGUF-загрузчик** получил лимиты на счётчики — битый/злой файл больше
  не уронит процесс в OOM.
- **Autograd-движок** сериализован — параллельные `backward()` больше не
  дают молча неверные градиенты.

## 🛠 Сборка — для людей, без боли

- **CMake Presets** — единый вход: `cmake --preset linux-x86_64` (или
  `windows-cpu`, `elbrus`, `alt/astra/redos`, `baikal`, `cuda`).
- **Убраны все хардкод-пути** из сборочных скриптов — больше никаких
  `C:/Users/...`, у которых ломалось у всех кроме автора.
- **Эльбрус**: один скрипт `build-elbrus.sh` сам определяет ISA (v3–v6) и
  BLAS (EML → OpenBLAS → встроенное микроядро). Поддержка от E2S до E16C.
- **PromeServe «скачал-запустил»** — готовый бинарь + web UI в релизах.

## 📚 Документация и честность

- **Сайт документации** (MkDocs Material, светлая/тёмная тема) +
  единый `docs/BUILD.md`.
- **STATS.md** — числа проекта (backward-функции, CUDA-ядра, оптимизаторы,
  тесты) теперь генерируются из кода, single source of truth. CI ловит
  расхождения.

  значит. Добавлены тесты PromeServe.
