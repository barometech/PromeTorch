# PromeTorch — Обновы на 10 день лета! ☀️

Большой апдейт: быстрее, безопаснее и наконец-то **собирается у всех**.

## 🚀 Производительность и квантизация

- **pre-SINQ GGUF (Huawei, Apache-2.0)** — грузим Sinkhorn-квантизованные
  модели Huawei как drop-in, без изменений кода. На Эльбрусе 8C2:
  **11.5 tok/s** (быстрее обычного baseline 10.6!).
- **Q5_K в Tensor-Parallel** — добавили K-slice. Любой Q4_K_S/Q5_K GGUF
  в TP больше не падает в медленный fallback (8.1 → 11.5 tok/s).
- **Q3_K dequant переписан bit-exact** по GGML — раньше молча выдавал
  мусор на Q3_K (DeepSeek/Mistral), теперь корректно.

## 🔒 Безопасность

- **PromeServe** слушает **127.0.0.1 по умолчанию**, не весь мир. Наружу —
  только осознанно через `PROMESERVE_HOST=0.0.0.0`.
- **Sandbox файловых инструментов** усилен — закрыт path-traversal/symlink.
- **GGUF-загрузчик** получил лимиты — битый файл больше не уронит в OOM.
- **Autograd-движок** сериализован — параллельные `backward()` больше не
  дают молча неверные градиенты.

## 🛠 Сборка — для людей, без боли

- **CMake Presets** — единый вход: `cmake --preset linux-x86_64`
  (или `windows-cpu`, `elbrus`, `alt/astra/redos`, `baikal`, `cuda`).
- **Убраны все хардкод-пути** из сборочных скриптов — больше никаких
  `C:/Users/...`, что ломалось у всех кроме автора.
- **Эльбрус**: `build-elbrus.sh` сам определяет ISA (v3–v6) и BLAS
  (EML → OpenBLAS → встроенное микроядро). От E2S до E16C.
- **PromeServe «скачал-запустил»** — готовый бинарь + web UI в релизах.

## 📚 Документация и честность

- **Сайт документации** (MkDocs Material, светлая/тёмная тема).
- **STATS.md** — числа проекта генерируются из кода, single source of

- **CI больше не врёт** — убраны `|| true`, зелёный значок снова значит.
